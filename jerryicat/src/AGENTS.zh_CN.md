# src/ 规则

本目录放启动器外壳、应用注册表和共享 UI 套件。这里也是唯一负责在玩法与设备端工具之间切换的地方。

## 职责

- 启动器 UI：应用列表或网格、选中、焦点、滚动、转场，以及玩法/工具的分组呈现。
- 应用生命周期编排：请求 `stop`、等待或汇合工作任务退出，再调用 `exit` 并删除页面。
- 注册表：一张显式的应用描述符表。表顺序就是启动器顺序；只能在该表添加条目，不得借助 linker 技巧或自动发现。
- 共享 UI 套件：通用控件、电量指示、标题栏、空状态/错误状态，以及被多个应用复用的时间或布局辅助。

玩法专属的规则、计分、页面和文案不得放在这里。

## 运行时规则

- 所有 LVGL 操作都在 LVGL 任务中、或持有 `bsp_lvgl_lock()` 时执行。不得在持锁期间做阻塞操作、音频、网络调用或等待任务。
- 按键事件从 `main/` 进入；启动器分发事件时不得阻塞。慢转场或应用启动不得卡住输入路径。
- 离开应用时，先停止其工作，再删除页面，最后重置启动器焦点与状态。应用启动失败时回到启动器并显示可读错误，不能留下半成品页面。
- 不设应用专属全局变量。共享状态使用模块内的 `s_` 状态，并写明所有者与重置路径。
- 控制静态 RAM：不得为每个应用预留全屏缓冲，不放大块注册表字符串。内容放在各应用自己的目录。

## 代码形态

- 文件 `jerryicat_<topic>.c`；内部符号 `static`；文件内状态 `s_`。
- 把导航、选中和计时逻辑抽成普通 C 模块，使 host tests 不依赖 LVGL 即可编译。UI 绘制保持薄。
- 注释解释所有权、调用顺序和失败行为，而不是逐行复述代码。

## 验证

为抽出的逻辑在 `../tests/` 添加或更新测试。渲染改动需要真机检查；主机编译不能证明屏幕显示。
