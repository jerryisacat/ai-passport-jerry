# fork 素材登记

本文件记录 `assets/` 下 fork 专用二进制素材的来源。工作规则见 [`AGENTS.zh_CN.md`](AGENTS.zh_CN.md)。

目前还没有登记任何素材。

## 如何添加条目

为每个素材添加一节，写明：

- 文件路径与用途。
- 来源 URL、作者或字库名、授权，以及允许再分发的说明。
- 转换器或工具版本，以及使用的完整命令。
- 尺寸、字符集、采样率、声道、位深等定义输出的参数。
- 提交文件的 SHA-256 校验和。

中英文两份文件必须在同一次改动中保持一致。
