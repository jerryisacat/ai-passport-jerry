# plus-one

最小的完整玩法：屏幕上一个数字，每按下三个按键中的任意一个就加一。它用来端到端
验证启动器、输入与生命周期通路。

## 页面与流程

- 启动器条目：标题 `+1`，类别 `PLAY`。
- 计数页：左上角品牌 `+1`，右上角电量，中间大号强调色数字，下面
  `PRESSES THIS SESSION`，底部提示 `PRESS ANY KEY +1 / HOLD OK BACK`。
- 离开玩法再进入，本次运行内的计数保留。

## 操作

- `UP`、`DOWN`、`OK` 按下：加一。在按下事件上计数，每次物理按压恰好一次，连按与双击都不丢。
- `OK` 长按：启动器保留的返回手势；启动这次长按的按压已经像普通按压一样计过一次。
- `CLICK`、`DOUBLE`、`RELEASE` 以及 `UP`/`DOWN` 长按不再重复计数。

## 状态与持久化

- 文件内一个 `uint32_t`，到 `UINT32_MAX` 后饱和，不回绕。
- 仅保留在本次运行中。不写 NVS，重启后归零；这里如实记录该限制，不假装持久化。

## 任务、资源与退出清理

- 没有工作任务、定时器、音频、网络或存储访问。
- 尚未实现空闲背光或休眠策略；玩法打开期间屏幕保持点亮。作为最终功耗版本前需补超时处理。
- `enter` 在已持有 LVGL 锁时创建并载入页面。
- `exit` 删除页面并清空控件指针；计数保留。

## 测试

- `../../tests/test_plus_one_logic.c` 通过纯头文件 `plus_one_logic.h` 覆盖加一与饱和。
- 运行 `../../tools/validate.sh` 执行 fork host tests。

## 真机检查

- 每次物理按压恰好加一；连按与双击不丢。
- 长按 `OK` 返回启动器；启动这次手势的按压计一次。
- 重新进入 `+1` 计数仍在；重启从 0 开始。
- 48 px 数字清晰可读；电量计不可用时右上角留空。

## 文件

- `plus_one.c` —— 应用描述符、页面与按键处理。
- `plus_one_logic.h` —— 饱和加一逻辑，可 host test，不依赖 ESP-IDF 或 LVGL。
